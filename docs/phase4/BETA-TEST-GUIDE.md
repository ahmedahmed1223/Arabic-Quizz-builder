# 🧪 دليل Beta Test — V15.0

> **الهدف**: اختبار شامل لـ V15.0 مع 50 معلماً قبل الإطلاق العام
> **المدة**: أسبوعان (التجميع + الاختبار + التحليل)
> **الحالة**: جاهز للتنفيذ

---

## 📋 المراحل

### المرحلة 1: التجهيز (يومان)

#### تجنيد المختبرين
- [ ] إنشاء نموذج تسجيل (Google Forms)
- [ ] نشر الدعوة في مجموعات المعلمين (Telegram، Facebook، LinkedIn)
- [ ] اختيار 50 معلماً متنوعاً:
  - 20 معلم مدارس ابتدائية
  - 15 معلم مدارس إعدادية
  - 10 معلم مدارس ثانوية
  - 5 مدربين/محاضرين جامعيين
- [ ] إرسال دعوات بالبريد الإلكتروني مع:
  - رابط تحميل APK
  - رابط النسخة الويب
  - دليل البدء السريع
  - رابط استبيان ما قبل الاختبار

#### ما قبل الاختبار (Pre-test Survey)
- [ ] اسم المعلم ومدرسته
- [ ] المادة التي يُدرّسها
- [ ] المرحلة الدراسية
- [ ] خبرته التقنية (مبتدئ/متوسط/متقدم)
- [ ] الأجهزة المتاحة (لابتوب/تابلت/هاتف/بروجكتر)
- [ ] توقعاته من التطبيق

---

### المرحلة 2: الاختبار الميداني (أسبوع)

#### سيناريوهات الاختبار الإلزامية

كل معلم يجب أن يُجرب السيناريوهات التالية ويُسجّل ملاحظاته:

**السيناريو 1: الإعداد الأول (15 دقيقة)**
- [ ] فتح التطبيق على المتصفح
- [ ] إدخال كلمة المرور الافتراضية (1234)
- [ ] تغيير كلمة المرور
- [ ] إكمال معالج الإعداد (3 خطوات)
- [ ] تغيير اللغة (عربي ↔ إنجليزي)
- [ ] تغيير السمة (داكن ↔ فاتح)

**السيناريو 2: إنشاء مسابقة (30 دقيقة)**
- [ ] إضافة قسم جديد "تاريخ"
- [ ] إضافة 5 أسئلة متنوعة:
  - 2 سؤال اختيار من متعدد
  - 1 سؤال صح/خطأ
  - 1 سؤال أكمل الفراغ
  - 1 سؤال صورة (اختياري)
- [ ] إضافة فريقين (الأحمر، الأزرق)
- [ ] تعيين ألوان وأسماء
- [ ] حفظ المسابقة

**السيناريو 3: تشغيل مسابقة (20 دقيقة)**
- [ ] بدء العرض التقديمي
- [ ] فتح شاشة الجمهور
- [ ] تشغيل سؤال واحد على الأقل
- [ ] استخدام مؤقت الأسئلة
- [ ] تسجيل نقاط الفرق
- [ ] استخدام وسيلة مساعدة (50/50 أو تخطّي)
- [ ] إنهاء المسابقة وعرض المنصة

**السيناريو 4: الاستيراد/التصدير (15 دقيقة)**
- [ ] تصدير المسابقة كـ JSON
- [ ] تصدير كـ Excel (XLSX)
- [ ] استيراد مسابقة من JSON
- [ ] استيراد من المكتبة الخارجية (إن توفّر اتصال)

**السيناريو 5: الميزات الجديدة في V15.0 (20 دقيقة)**
- [ ] تجربة توليد الأسئلة بالذكاء الاصطناعي
- [ ] فتح لوحة التحليلات التعليمية
- [ ] تصدير تقرير PDF
- [ ] تصدير تقرير Excel
- [ ] تجربة وضع تعدد اللاعبين (إن توفّر خادم)
- [ ] تثبيت التطبيق كـ PWA (Chrome → Install)

**السيناريو 6: تطبيق أندرويد (15 دقيقة — اختياري)**
- [ ] تثبيت APK على هاتف أندرويد
- [ ] فتح التطبيق
- [ ] اختبار التنقل السفلي
- [ ] اختبار اللمس (سحب، نقرة طويلة)
- [ ] اختبار اهتزاز الإجابات

## 🐛 تتبّع الأخطاء

كل خطأ يُبلّغ عنه يجب أن يحتوي:
1. **الوصف**: ما حدث؟
2. **الخطوات**: كيف نُعيد إنتاجه؟
3. **المتوقع**: ماذا توقع؟
4. **الفعلي**: ماذا حدث؟
5. **البيئة**: جهاز + متصفح + إصدار
6. **لقطات الشاشة/الفيديو** (إن أمكن)

**قنوات الإبلاغ**:
- GitHub Issues (للمطورين)
- نموذج Google Forms (للمعلمين غير التقنيين)
- مجموعة Telegram خاصة للمختبرين

## 📈 تحليل النتائج

بعد انتهاء فترة الاختبار:

1. **تجميع البيانات**: تصدير جميع الاستجابات من Google Forms
2. **تحليل كمي**: متوسطات، انحرافات، نسب
3. **تحليل نوعي**: تجميع التعليقات حسب الموضوع
4. **أولوية الإصلاحات**:
   - P0: أخطاء تمنع الاستخدام (إصلاح فوري)
   - P1: أخطاء تُحبط التجربة (إصلاح قبل الإطلاق)
   - P2: تحسينات تجميلية (إصلاح لاحقاً)
5. **تقرير نهائي**: ملخص للنتائج + قرارات الإطلاق
